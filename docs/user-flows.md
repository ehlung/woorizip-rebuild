# 우리.zip 사용자 흐름과 화면 목록

이 문서는 모바일 앱의 사용자 흐름과 화면 구성을 정의한다. 디자인 시스템과 화면 디자인(2단계)의 입력이 되고, 화면별 표시 데이터는 API와 ERD 설계(3단계)의 근거가 된다.

웹 클라이언트의 흐름은 웹 구축 단계에서 별도로 정의한다.

## 1. 기존 구현에서 바꾸는 것

| 기존 구현                                                            | 문제                                          | 리빌드                                                   |
| -------------------------------------------------------------------- | --------------------------------------------- | -------------------------------------------------------- |
| 회원가입 9단계 (약관, 이메일, 별명, 프로필, 생년월일, 전화번호, 가족 코드 등) | 생년월일, 전화번호는 서비스에서 쓰이지 않음. 가입 후 다시 로그인해야 함 | 필요한 정보만 받고, 가입 완료 시 바로 로그인 상태        |
| 초대 링크로 진입해도 코드 입력칸이 비어 있음                         | 초대 흐름이 끊김                              | 링크로 진입하면 초대 코드 자동 입력                      |
| 촬영 후 AI 분석이 끝날 때까지 로딩 화면에서 대기                     | 동기식 분석 구조                              | 업로드 후 바로 홈으로 이동, 카드에 분석 상태 표시        |
| 얼굴 정렬 안내가 음성뿐                                              | 화면으로 위치를 확인할 수 없음                | 음성 안내와 화면 가이드를 함께 제공                      |
| 지난 주 질문을 선택해도 이번 주 답변이 표시됨                        | 과거 답변 열람 불가                           | 보관함의 주차별 보기로 재설계                            |
| 이번 주 질문에만 답변 가능                                           | 한 주를 놓치면 기록이 비게 됨                 | 지난 질문에도 답변 가능                                  |
| 반응 기능 없음, 카카오 로그인 미연동                                 | 미구현                                        | 반응 추가, 카카오/애플 로그인 연동                       |
| 알림 없음                                                            | 가족이 새 질문과 답변을 알기 어려움           | 푸시 알림과 앱 내 알림 목록 제공                         |
| 글자 크기만 기본/크게 두 단계로 조절                                 | 버튼, 간격, 아이콘은 그대로라 화면 균형이 깨짐 | 글자, 간격, 버튼, 아이콘까지 함께 바뀌는 화면 크기 3단계 |

기존 구현에서 이어가는 것:

- 한 화면에 한 가지만 묻는 가입 단계
- 크고 누르기 쉬운 버튼
- 질문 읽어주기
- 크기 조절 설정 (화면 크기 3단계로 확장)
- 말풍선 형태의 답변 카드

## 2. 주요 결정

| 항목            | 결정                                                                                   |
| --------------- | -------------------------------------------------------------------------------------- |
| 가족 소속       | 한 사용자는 하나의 가족에만 속한다 (모델은 여러 가족 소속으로 확장 가능)                |
| 로그인          | 이메일, 카카오, 애플                                                                   |
| 질문 배정       | 가족 생성 시점을 기준으로 매주 새 질문이 배정된다 (배정 요일 기준은 백엔드 설계 시 확정) |
| 답변 개수       | 한 사람은 한 질문에 답변 하나를 남긴다. 다시 촬영하면 기존 답변을 교체한다              |
| 늦은 답변       | 지난 주 질문에도 답변할 수 있다                                                        |
| 지난 답변 소통  | 지난 주 답변에도 댓글과 반응을 남길 수 있다                                            |
| 가족 나가기와 탈퇴 | 가족 나가기(계정 유지)와 회원 탈퇴(계정 삭제)를 구분한다. 떠날 때 내 답변을 가족 보관함에 남길지 직접 선택한다 |
| 질문 읽어주기   | 기기 내장 TTS를 사용한다 (서버 호출 없음)                                              |
| 화면 크기       | 작게 / 보통 / 크게 3단계. 글자, 간격, 버튼, 아이콘이 함께 바뀌고 필요하면 배치도 바뀐다. 가입 중에 선택하고 내 정보에서 변경한다 |
| 알림            | 푸시 알림과 앱 내 알림 목록을 제공한다                                                 |
| 일상 기록       | 후순위                                                                                 |
| 쪽지함          | 실시간 채팅이 아닌 편지 형태로, 후순위                                                 |

## 3. 내비게이션 구조

탭은 "이번 주", "지난 시간", "사람", "설정"으로 역할을 나눈다.

```txt
탭 바: 홈 · 보관함 · 가족 · 내 정보

홈        이번 주   이번 주 질문, 가족 답변, [답변하기], 알림 목록 진입
보관함    지난 시간  주차별 기록, 검색
가족      사람      구성원 목록(이번 주 답변 여부, 최근 답변), 구성원별 답변 모음, 초대
내 정보   설정      프로필, 화면 크기, 알림 설정, 로그인 수단, 가족 설정, 계정
```

- 구성원별 답변 모음은 보관함이 아닌 가족 탭에 둔다. 같은 목록이 두 곳에 생기지 않게 하고, 가족 탭이 가족의 근황을 확인하는 곳이 되도록 하기 위해서다.
- 가족 이름 변경, 초대 코드 재발급처럼 자주 쓰지 않는 관리 기능은 내 정보의 가족 설정에 둔다.
- 후순위 기능(편지, 일상 기록 등)을 추가해도 탭 구조는 바꾸지 않는다. 익숙해진 탭 위치가 바뀌는 것은 고령 사용자에게 큰 부담이다.
- 탭 바는 탭의 첫 화면에서만 표시한다.
- 촬영, 답변 상세처럼 한 가지 일에 집중하는 화면은 탭 바 없이 전체 화면으로 연다.

## 4. 사용자 흐름

### A. 시작과 가입

```txt
스플래시
-> 로그인 (이메일 / 카카오 / 애플)
   ├ 기존 사용자: 가족이 있으면 홈, 없으면 가족 연결
   └ 처음 가입
      -> 약관 동의
      -> (이메일 가입인 경우) 이메일, 비밀번호 입력
      -> 프로필 설정 (이름, 사진은 선택)
      -> 화면 크기 선택 (미리보기를 보며 작게 / 보통 / 크게 선택)
      -> 가족 연결
         ├ 초대 코드 입력 (초대 링크로 진입했다면 자동 입력) -> 가족 확인 -> 호칭 선택 -> 홈
         └ 새 가족 만들기 -> 가족 이름 -> 호칭 선택 -> 초대 코드 공유 -> 홈
-> 홈 진입 후 알림 권한 요청
```

- 알림 권한은 앱을 처음 열 때가 아니라, 가족 연결을 마친 뒤 요청한다. 알림이 왜 필요한지 이해한 상태에서 요청해야 허용률이 높다.

### B. 이번 주 질문에 답변하기

```txt
홈 (이번 주 질문, 읽어주기, 가족 답변 현황)
-> [답변하기]
-> 촬영 (얼굴 위치 음성·화면 가이드, 녹화 시작/종료)
-> 미리보기 ([다시 찍기] / [올리기])
-> 업로드 (진행률 표시, 실패 시 재시도)
-> 홈으로 복귀, 내 카드에 "AI가 정리하는 중"
-> 분석 완료 시 카드에 썸네일, 제목, 요약 표시 (푸시 알림)
-> 필요하면 답변 상세에서 제목, 요약, 썸네일 수정
```

- 분석이 실패해도 영상은 재생할 수 있고, 카드는 기본 썸네일과 질문 문구로 표시한다. 상세 화면에서 재분석을 요청할 수 있다.
- 이미 답변한 질문에서 [답변하기]를 누르면 "다시 찍으면 기존 답변이 교체됩니다" 확인 후 촬영으로 이동한다.

### C. 가족 답변 보고 반응하기

```txt
푸시 알림 / 홈 / 보관함 / 가족 탭의 답변 카드
-> 답변 상세 (영상 재생, 제목, 요약, 반응, 댓글)
-> 반응 남기기 / 댓글 작성·수정·삭제
```

- 답변 상세는 어디에서 열든 같은 화면이다. 지난 주 답변에도 댓글과 반응을 남길 수 있다.

### D. 지난 기록 다시 보기

```txt
보관함
├ 주차별: 질문 목록 -> 그 주의 질문과 가족 답변 -> 답변 상세
│         (아직 답하지 않은 질문이면 [답변하기]로 늦은 답변)
└ 검색: 자연어 검색어 입력 -> 결과 목록 -> 답변 상세
```

### E. 가족 보기와 초대

```txt
가족 탭 (구성원 목록: 이번 주 답변 여부, 최근 답변)
-> 구성원 선택 -> 구성원 프로필 (그 구성원의 답변 모음) -> 답변 상세
-> [초대하기] 초대 링크와 코드 공유 (공유 시트)
```

### F. 알림

```txt
푸시 알림 탭 -> 해당 화면으로 바로 이동 (질문이면 홈, 답변·댓글·반응이면 답변 상세)
홈의 알림 아이콘 -> 알림 목록 -> 해당 화면
내 정보 -> 알림 설정 (종류별 켜기/끄기, 방해 금지 시간)
```

| 알림                 | 받는 사람            | 이동 화면   |
| -------------------- | -------------------- | ----------- |
| 새 질문 도착         | 가족 전체            | 홈          |
| 가족이 답변을 올림   | 작성자를 제외한 가족 | 답변 상세   |
| 내 답변 분석 완료    | 작성자               | 답변 상세   |
| 내 답변 분석 실패    | 작성자               | 답변 상세   |
| 내 답변에 댓글       | 답변 작성자          | 답변 상세   |
| 내 답변에 반응       | 답변 작성자          | 답변 상세   |
| 새 구성원 가입       | 가족 전체            | 가족 탭     |

- 짧은 시간에 여러 반응이 달리면 하나의 알림으로 묶는다.
- 방해 금지 시간에 발생한 알림은 푸시를 보내지 않고 알림 목록에만 남긴다.

### G. 내 정보와 계정

```txt
내 정보 -> 프로필 수정 (이름, 사진, 호칭)
        -> 화면 크기
        -> 알림 설정
        -> 로그인 수단 관리 (연결된 수단 확인, 카카오/애플/이메일 연결)
        -> 가족 설정 (가족 정보, 방장은 가족 이름 변경과 초대 코드 재발급, 방장 넘기기, 가족 나가기)
        -> 계정 (로그아웃, 회원 탈퇴)
```

### H. 가족 나가기와 회원 탈퇴

```txt
[가족 나가기] 계정은 유지하고 가족에서만 나간다
가족 설정 -> [가족 나가기]
-> (방장이면) 다른 구성원에게 방장 넘기기 먼저
-> 내 답변 처리 선택: 가족 보관함에 남기기 / 모두 삭제
-> 확인 -> 가족 연결 화면 (다른 가족에 가입하거나 새 가족 만들기)

[회원 탈퇴] 가족 나가기 + 계정 삭제
계정 -> [회원 탈퇴]
-> (방장이면) 방장 넘기기 먼저
-> 내 답변 처리 선택: 가족 보관함에 남기기 / 모두 삭제
-> 30일 유예 안내 -> 확인 -> 로그아웃
-> 30일 안에 다시 로그인하면 복구, 지나면 영구 삭제
```

| 선택                | 영상 답변                               | 댓글, 반응                                   |
| ------------------- | --------------------------------------- | -------------------------------------------- |
| 가족 보관함에 남기기 | 이름, 사진, 호칭과 함께 그대로 남는다   | 이름, 사진, 호칭과 함께 그대로 남는다        |
| 모두 삭제           | 영상, 썸네일, 전사, 요약, 검색 데이터 삭제 | 남기되 작성자를 "떠난 구성원"으로 표시        |

- 남기기를 선택하면 떠났다는 표시를 하지 않는다. 가족을 떠난 이유에는 사별도 있을 수 있으므로, 남은 가족에게는 기록이 원래 모습 그대로 보여야 한다.
- 떠난 구성원은 가족 탭의 구성원 목록, 이번 주 답변 현황, 알림 대상에서 제외한다. 남긴 답변은 보관함과 답변 상세에서 그대로 보이고, 작성자를 누르면 그 구성원의 답변 모음이 열린다.
- 남기기를 선택할 때는 "탈퇴 후에는 남긴 기록을 직접 삭제할 수 없습니다"를 안내한다.
- 떠날 때 답변 처리는 미리 선택된 기본값 없이 본인이 직접 고른다.
- 마지막 구성원이 가족을 나가면 가족 공간 전체를 삭제한다.

### 공통 상태

모든 목록과 상세 화면은 다음 상태를 공통 컴포넌트로 표현한다.

- 로딩
- 빈 상태 (예: "아직 가족이 초대되지 않았어요", "첫 번째 답변을 남겨보세요")
- 오류와 다시 시도
- 분석 중 / 분석 실패

## 6. 후순위 기능의 위치

지금 화면 구조에 포함하지 않지만, 추가할 때 들어갈 자리를 미리 정해 둔다. 어떤 기능을 추가해도 탭 구조는 유지한다.

| 기능           | 위치                                                   |
| -------------- | ------------------------------------------------------ |
| 편지(쪽지함)   | 가족 탭 상단의 편지함(받은 편지, 안 읽은 편지 표시), 구성원 프로필의 [편지 쓰기] |
| 일상 기록      | 보관함의 한 섹션                                       |
| 질문 추천      | 홈의 다음 주 질문 미리보기, 가족 설정                  |
| 반려동물 숏츠  | 보관함의 한 섹션                                       |
| 방장 권한 요청 | 가족 설정에서 구성원이 방장 권한을 요청하고, 방장이 알림을 받아 수락/거절 |
