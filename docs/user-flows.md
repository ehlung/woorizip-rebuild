# 사용자 흐름과 화면 목록

이 문서는 모바일 앱의 사용자 흐름과 화면 구성을 정리한다. 흐름의 각 단계와 화면에는 기능 단계(0~3단계)를 표시한다. 단계를 나눈 기준은 [02-domain-and-problem.md](02-domain-and-problem.md) 6장에, 단계별 기능 목록과 진행 상태는 [STATUS.md](STATUS.md)에 있다.

- 표시가 없는 항목은 0단계다. 1단계 이상은 `(1단계)`처럼 적는다.
- 화면 뒤의 구조(업로드, 분석, 알림 발송, 탈퇴 처리)는 [03-architecture.md](03-architecture.md)에 있다.
- 2단계 웹의 흐름은 웹을 만들 때 따로 정한다.

## 1. 기존 구현에서 바꾸는 것

| 기존 구현 | 문제 | 리빌드 |
| --- | --- | --- |
| 회원가입 9단계 (약관, 이메일, 별명, 프로필, 생년월일, 전화번호, 가족 코드 등) | 생년월일, 전화번호는 서비스에서 쓰이지 않음. 가입 후 다시 로그인해야 함 | 필요한 정보만 받고, 가입이 끝나면 바로 로그인 상태 |
| 촬영 후 AI 분석이 끝날 때까지 로딩 화면에서 대기 | 업로드가 분석을 기다림(P-05) | 업로드 후 바로 홈으로 이동하고, 카드에 분석 상태 표시([ADR 0002](adr/0002-async-analysis.md)) |
| 업로드 중 새로고침하면 녹화본이 사라짐 | 실패하면 처음부터 다시 찍어야 함(P-10) | 서버가 받았다고 확인하기 전까지 녹화본을 기기에 두고 다시 올리기([ADR 0004](adr/0004-failure-and-retry.md)) |
| 분석이 실패하면 업로드 전체가 실패 | 기록을 잃음(P-07) | 분석이 실패해도 답변은 남고, 기본값으로 보임([ADR 0004](adr/0004-failure-and-retry.md)) |
| 지난 주 질문을 선택해도 이번 주 답변이 표시됨 | 지난 기록을 볼 수 없음(P-16) | 보관함의 주차별 보기로 다시 설계 |
| 반응 기능 없음, 알림 없음 | 가족이 답변을 봤는지, 새 질문이 왔는지 알기 어려움 | 반응과 푸시 알림을 0단계에 둠 |
| 글자 크기만 기본/크게 두 단계로 조절 | 버튼, 간격, 아이콘은 그대로라 화면 균형이 깨짐(P-23) | 글자, 간격, 버튼, 아이콘이 함께 바뀌는 화면 크기 3단계([ADR 0015](adr/0015-screen-size-and-accessibility.md)) |
| 회원 탈퇴 미구현 | 스토어 정책 위반 | 0단계에 회원 탈퇴, 1단계에 떠날 때 답변 남기기·삭제 선택 |
| 이번 주 질문에만 답변 가능 | 한 주를 놓치면 기록이 빔 | 지난 질문에도 답변 (1단계) |
| 얼굴 정렬 안내가 음성뿐 | 화면으로 위치를 확인할 수 없음 | 음성과 화면 가이드를 함께 제공 (1단계) |

기존 구현에서 이어가는 것:

- 한 화면에 한 가지만 묻는 가입 단계
- 크고 누르기 쉬운 버튼
- 말풍선 형태의 답변 카드
- 질문 읽어주기 (1단계)

## 3. 내비게이션 구조

탭은 "이번 주", "지난 시간", "사람", "설정"으로 역할을 나눈다.

```txt
탭 바: 홈 · 보관함 · 가족 · 내 정보

홈      이번 주    이번 주 질문, 가족 답변, [답변하기], 알림 목록 진입(1단계)
보관함  지난 시간  주차별 기록, 정렬·필터와 제목 검색(1단계), 의미 검색(2단계)
가족    사람      구성원 목록, 초대, 구성원별 답변 모음(1단계)
내 정보 설정      화면 크기, 계정, 프로필·알림·로그인 수단·가족 설정(1단계)
```

- 구성원별 답변 모음은 보관함이 아닌 가족 탭에 둔다. 같은 목록이 두 곳에 생기지 않게 하고, 가족 탭이 가족의 근황을 확인하는 곳이 되도록 하기 위해서다.
- 이후 단계의 기능을 추가해도 탭 구조는 바꾸지 않는다. 익숙해진 탭 위치가 바뀌는 것은 연세가 많은 사용자에게 큰 부담이다.
- 탭 바는 탭의 첫 화면에서만 표시한다. 촬영, 답변 상세처럼 한 가지 일에 집중하는 화면은 탭 바 없이 전체 화면으로 연다.

## 4. 사용자 흐름

### A. 시작과 가입

```txt
스플래시
-> 로그인 (이메일 / 카카오·구글·애플은 1단계)
   ├ 기존 사용자: 가족이 있으면 홈, 없으면 가족 연결
   └ 처음 가입
      -> 약관 동의 (서비스 이용, 개인정보 처리, 영상·음성의 외부 AI 전송, 14세 이상 확인)
      -> 이메일, 비밀번호 입력
      -> 이름 입력
      -> 화면 크기 선택 (미리보기를 보며 작게 / 보통 / 크게)
      -> 가족 연결
         ├ 초대 코드 입력 -> 가족 확인 -> 호칭 선택 -> 홈
         │  (초대 링크로 들어오면 코드 자동 입력: 1단계)
         └ 새 가족 만들기 -> 가족 이름 -> 호칭 선택 -> 초대 코드 공유 -> 홈
-> 홈에 들어온 뒤 알림 권한 요청
```

- 가입이 끝나면 바로 로그인 상태가 된다.
- 알림 권한은 앱을 처음 열 때가 아니라 가족 연결을 마친 뒤 요청한다. 알림이 왜 필요한지 이해한 상태에서 요청해야 허용률이 높다.
- 가입 중 입력한 비밀번호는 화면 흐름 안의 메모리 상태로만 다룬다([ADR 0009](adr/0009-auth-token.md)).

### B. 비밀번호 재설정

```txt
로그인 -> [비밀번호를 잊었어요]
-> 이메일 입력 -> 메일로 받은 6자리 코드 입력
-> 새 비밀번호 입력 -> 로그인 화면
```

- 코드는 10분 뒤 만료되고, 5회 틀리면 무효가 된다. 다시 요청할 수 있지만 횟수에 제한이 있다.
- 재설정이 끝나면 다른 기기의 로그인도 모두 끊긴다.
- 가입하지 않은 이메일을 넣어도 같은 안내를 보여준다. 가입 여부를 알 수 없게 하기 위해서다.

### C. 이번 주 질문에 답변하기

```txt
홈 (이번 주 질문, 가족 답변 현황)
-> [답변하기]
-> 촬영 (녹화 시작/종료, 남은 시간)
   (질문 읽어주기, 얼굴 위치 음성·화면 가이드: 1단계)
-> 미리보기 ([다시 찍기] / [올리기])
-> 업로드 (진행률 표시)
   └ 실패하면 녹화본을 기기에 두고 [다시 올리기]
-> 홈으로 돌아가고, 내 카드에 "AI가 정리하는 중"
-> 분석이 끝나면 카드에 썸네일, 제목, 요약
   (홈을 보고 있으면 화면이 바로 바뀌고, 앱 밖에 있으면 푸시 알림)
-> 필요하면 답변 상세에서 제목, 요약 수정
```

- 분석이 끝내 실패해도 영상은 재생된다. 카드는 질문 문구와 기본 이미지로 보이고, 작성자에게 "AI 정리가 안 됐어요, 직접 적어 주세요" 푸시 알림이 간다.
- 이미 답변한 질문에서 [답변하기]를 누르면 "다시 찍으면 기존 답변이 바뀝니다"를 확인한 뒤 촬영으로 이동한다.
- 하루 다시 찍기 횟수(20회)를 넘으면 "오늘은 더 다시 찍을 수 없어요. 내일 다시 해 주세요"를 보여준다.
- 썸네일 프레임 고르기와 다시 분석 요청은 1단계다.

### D. 가족 답변 보고 반응하기

```txt
푸시 알림 / 홈 / 보관함의 답변 카드
-> 답변 상세 (영상 재생, 제목, 요약, 반응)
-> 반응 남기기
   (댓글 작성·수정·삭제: 1단계)
```

- 답변 상세는 어디에서 열든 같은 화면이다. 지난 주 답변에도 반응을 남길 수 있다.
- 반응은 구성원 한 명이 답변 하나에 하나를 남긴다.

### E. 지난 기록 다시 보기

```txt
보관함
├ 주차별: 질문 목록 -> 그 주의 질문과 가족 답변 -> 답변 상세
│         (아직 답하지 않은 질문에 늦은 답변: 1단계)
├ 정렬·필터, 제목 검색 (1단계)
└ 의미 검색: 자연어 검색어 -> 결과 목록 -> 답변 상세 (2단계)
```

### F. 가족 보기와 초대

```txt
가족 탭 (구성원 목록: 이름, 호칭, 방장 여부, 이번 주 답변 여부)
-> [초대하기] 초대 코드와 링크 공유 (공유 시트)
-> 구성원 선택 -> 구성원 프로필 (그 구성원의 답변 모음) -> 답변 상세 (1단계)
```

### G. 알림

```txt
푸시 알림을 누름 -> 해당 화면으로 바로 이동 (새 질문이면 홈, 나머지는 답변 상세)
홈의 알림 아이콘 -> 알림 목록 -> 해당 화면 (1단계)
내 정보 -> 알림 설정 (종류별 켜기/끄기, 방해 금지 시간) (1단계)
```

| 알림 | 받는 사람 | 이동 화면 | 단계 |
| --- | --- | --- | --- |
| 새 질문 도착 | 가족 전체 | 홈 | 0 |
| 가족이 답변을 올림 | 작성자를 제외한 가족 | 답변 상세 | 0 |
| 내 답변 분석 완료 | 작성자 | 답변 상세 | 0 |
| 내 답변 분석 실패 | 작성자 | 답변 상세 | 0 |
| 내 답변에 반응 | 답변 작성자 | 답변 상세 | 1 |
| 내 답변에 댓글 | 답변 작성자 | 답변 상세 | 1 |
| 새 구성원 가입 | 가족 전체 | 가족 탭 | 1 |

- 짧은 시간에 여러 반응이 달리면 하나의 알림으로 묶는다(1단계).
- 방해 금지 시간에 생긴 알림은 푸시를 보내지 않고 알림 목록에만 남긴다(1단계).
- 앱이 켜져 있을 때 온 알림을 어떻게 보여줄지는 알림 목록을 만드는 1단계에서 정한다.

### H. 내 정보와 계정

```txt
내 정보 -> 화면 크기
        -> 계정 (로그아웃, 회원 탈퇴)
        -> 프로필 수정 (이름, 사진, 호칭) (1단계)
        -> 알림 설정 (1단계)
        -> 로그인 수단 관리 (연결된 수단 확인, 카카오·구글·애플·이메일 연결) (1단계)
        -> 가족 설정 (가족 정보, 방장은 가족 이름 변경과 초대 코드 재발급, 방장 넘기기, 가족 나가기) (1단계)
```

### I. 회원 탈퇴와 가족 나가기

#### 0단계: 회원 탈퇴

```txt
계정 -> [회원 탈퇴]
-> 안내: "내 답변 N개와 반응이 모두 지워지고, 되돌릴 수 없어요"
-> 비밀번호 입력 -> 확인
-> 로그인 화면
```

- 계정과 내 답변(영상, 썸네일, 요약), 내 반응을 모두 지운다. 다른 가족의 답변은 그대로 남는다.
- 방장이 탈퇴하면 가장 먼저 가입한 구성원에게 방장이 자동으로 넘어간다. 마지막 구성원이 탈퇴하면 가족 공간을 지운다.
- 유예 기간은 두지 않는다. 지우는 데 걸리는 시간은 안내한다.
- 근거와 처리 순서는 [03-architecture.md](03-architecture.md) 9장에 있다.

#### 1단계: 떠날 때 직접 고르기

```txt
[가족 나가기] 계정은 두고 가족에서만 나간다
가족 설정 -> [가족 나가기]
-> (방장이면) 다른 구성원에게 방장 넘기기 먼저
-> 내 답변 처리 선택: 가족 보관함에 남기기 / 모두 지우기
-> 확인 -> 가족 연결 화면 (다른 가족에 들어가거나 새 가족 만들기)

[회원 탈퇴] 가족 나가기 + 계정 삭제
계정 -> [회원 탈퇴]
-> (방장이면) 방장 넘기기 먼저
-> 내 답변 처리 선택: 가족 보관함에 남기기 / 모두 지우기
-> 비밀번호 입력 -> 확인 -> 로그인 화면
```

| 선택 | 영상 답변 | 댓글, 반응 |
| --- | --- | --- |
| 가족 보관함에 남기기 | 이름, 사진, 호칭과 함께 그대로 남는다 | 이름, 사진, 호칭과 함께 그대로 남는다 |
| 모두 지우기 | 영상, 썸네일, transcript, 요약, 검색 데이터를 지운다 | 지운다 |

- 답변 처리는 미리 골라 둔 값 없이 본인이 직접 고른다.
- 남기기를 고르면 떠났다는 표시를 하지 않는다. 가족을 떠난 이유에는 사별도 있을 수 있으므로, 남은 가족에게는 기록이 원래 모습 그대로 보여야 한다.
- 남기기를 고를 때는 "탈퇴 후에는 남긴 기록을 직접 지울 수 없어요"를 안내한다. 남긴다는 사실과 범위는 개인정보 처리방침에도 적는다.
- 떠난 구성원은 가족 탭의 구성원 목록, 이번 주 답변 현황, 알림 대상에서 빠진다. 남긴 답변은 보관함과 답변 상세에서 그대로 보인다.
- 탈퇴 유예 기간을 둘지는 1단계에서 다시 판단한다.

### 공통 상태

모든 목록과 상세 화면은 다음 상태를 공통 컴포넌트로 보여준다([ADR 0015](adr/0015-screen-size-and-accessibility.md)).

- 로딩
- 빈 상태 (예: "아직 가족이 초대되지 않았어요", "첫 번째 답변을 남겨 보세요")
- 오류와 다시 시도. `alert`만 띄우고 끝내지 않고, 항상 다음 행동을 함께 보여준다
- AI 분석 중, AI 정리 실패

## 6. 2·3단계 기능의 위치

지금 화면에는 넣지 않지만, 추가할 때 들어갈 자리를 미리 정해 둔다. 어떤 기능을 추가해도 탭 구조는 유지한다.

| 기능 | 위치 | 단계 |
| --- | --- | --- |
| 의미 검색 | 보관함의 검색 | 2 |

| 방장 권한 요청 | 가족 설정에서 구성원이 요청하고, 방장이 알림을 받아 수락·거절 | 3 |
| 14세 미만 보호자 동의 가입 | 가입 때 보호자(가족 구성원) 동의 단계 추가 | 3 |
