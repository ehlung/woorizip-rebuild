# 0001. MVP 범위와 기능 우선순위

- 상태: 채택
- 날짜: 2026-11-19
- 관련 문제: 01의 5장(범위 문제), P-05, P-10, P-16 ([01-legacy-analysis.md](../01-legacy-analysis.md))

## 맥락

기존 프로젝트는 화면 47개 규모로 기능을 넓혔지만, 카카오 로그인, 이메일 변경, 음성 설정, 회원 탈퇴, 반려동물 숏츠 등 상당수가 미완성이거나 가짜 응답으로 동작했다(01의 5장). 반면 서비스의 핵심 흐름은 업로드가 AI 분석을 끝까지 기다렸고(P-05), 실패하면 복구할 경로가 없었으며(P-10), 지난 주차를 다시 보는 기능은 동작하지 않았다(P-16). 기능 수가 늘어나는 동안 핵심의 완성도는 낮았다.

기존 프로젝트에는 "얼굴·동작 인식 AI를 활용한다"는 졸업 프로젝트 조건이 있었고, 얼굴 가이드와 반려동물 인식 같은 기능은 이 조건에서 출발했다. 리빌드에는 이 조건이 없다.

리빌드는 1인 개발이고, 0단계를 2026년 안에 지인 대상 테스트 배포까지 마치는 것을 목표로 한다([02-domain-and-problem.md](../02-domain-and-problem.md) 2장). 테스트 배포에서 확신도가 낮은 니즈를 확인한 뒤 이후 범위를 다시 판단한다.

## 판단 기준

1. 서비스 정의("AI를 활용해 떨어져 사는 가족의 소통을 돕고, 그 기록을 다시 꺼내 볼 수 있게 한다")를 이루는가
2. 테스트 배포라도 지켜야 하는 법·스토어 정책에 필요한가
3. 1차 피드백에서 확인할 가정(02의 4장)을 검증하는 데 필요한가
4. 나중에 넣으면 비용이 큰 구조적 기반인가
5. 1인 개발로 목표 기간 안에 완성도 있게 만들 수 있는가

## 후보

### A. 기존 기능을 모두 다시 구현

- 장점: 기존 프로젝트와 같은 기능 범위를 유지한다. 기능이 빠졌다는 인상을 주지 않는다.
- 단점: 기존과 같은 실패를 반복할 가능성이 크다. 1인 개발로 목표 기간 안에 47개 화면 규모를 완성도 있게 만들 수 없다(기준 5).

### B. 핵심 흐름만 최소로 구현

질문, 촬영·업로드, AI 정리, 이번 주 답변 보기만 만든다.

- 장점: 가장 빨리 만들 수 있다.
- 단점:
  - 외부 AI 전송 동의, 회원 탈퇴처럼 테스트 배포에도 필요한 항목이 빠진다(기준 2).
  - 보관함과 반응이 없으면 "기록을 다시 본다", "반응이 다음 답변의 동기가 된다"는 가정을 확인할 수 없다(기준 3).
  - 화면 크기 3단계 구조를 나중에 넣으면 모든 화면을 다시 고쳐야 한다(기준 4).

### C. 서비스 정의, 출시 필수, 구조적 기반을 0단계로 두고 나머지를 1~3단계로 나눔

- 장점: 핵심 흐름의 완성도에 집중하면서, 테스트 배포에 필요한 항목과 가정 검증에 필요한 기능을 함께 갖춘다.
- 단점: B보다 만들 것이 많다. 기존 프로젝트에 있던 댓글, 카카오 로그인, 얼굴 가이드가 1차 테스트에는 없다.

## 결정

C를 채택한다. 단계 기준과 판단이 갈린 항목의 근거는 [02-domain-and-problem.md](../02-domain-and-problem.md) 6장에, 단계별 기능 목록은 [STATUS.md](../STATUS.md)에 둔다.

- A는 기존 프로젝트의 문제(기능 수가 핵심의 완성도를 앞섬)를 그대로 반복하므로 버린다.
- B는 기준 2~4를 채우지 못한다. 특히 보관함이 없으면 기록이 이번 주에서 끝나 서비스 정의의 "다시 꺼내 볼 수 있게"를 만족하지 못한다.
- 얼굴 가이드와 반려동물 기능은 졸업 프로젝트 조건에서 출발한 기능이므로, 사용자 니즈 기준으로 다시 판단해 1단계와 3단계로 둔다.

## 결과

- 얻는 것: 핵심 흐름을 실패에 대비된 상태로 먼저 완성한다. 1차 피드백에서 주요 가정을 확인할 수 있다.
- 잃는 것: 1차 테스트 사용자는 기존 프로젝트보다 기능이 적다고 느낄 수 있다. 댓글이 없어 가족 간 대화는 반응으로만 가능하다.
- 후속 작업: 1차 피드백 후 1~3단계의 범위와 순서를 다시 검토한다. 범위가 바뀌면 이 ADR을 대체하는 새 ADR을 쓴다.

## 검증

- 0단계 기능만으로 다음 시나리오를 끝까지 수행할 수 있다: 가입 → 가족 만들기와 초대 → 이번 주 질문에 영상 답변 → AI 제목·요약·썸네일 확인과 수정 → 가족이 반응 → 다음 주에 지난 주차 다시 보기
- 1차 피드백에서 "필요했는데 없던 기능"을 묻는다. 1~3단계 항목이 여러 사용자에게서 반복해서 나오면, 그 항목을 0단계로 올릴지 검토한다.
