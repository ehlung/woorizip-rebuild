## 기능 단계와 진행 상태

단계를 나눈 기준은 [02-domain-and-problem.md](02-domain-and-problem.md) 6장에 있다. 상태는 `미착수`, `화면 초안`, `설계`, `구현`, `검증 완료`로 표시한다. `화면 초안`은 클릭 가능한 디자인 프로토타입으로 화면 구성을 확인한 상태다.

### 1단계 (사용자 맞춤)

- 크게 단계 세부 조정, 질문 듣기, 얼굴 가이드
- 댓글
- 썸네일 프레임 고르기, 재분석 요청
- 늦은 답변 (지난 질문에 답하기)
- 구성원별 답변 모음, 보관함 정렬·필터, 제목 검색
- 카카오·구글·애플 로그인
- 알림 목록, 알림 설정, 나머지 알림 (분석 완료, 댓글, 반응)
- 가족 나가기, 방장 넘기기, 떠날 때 답변 남기기·삭제 선택
- 프로필 수정, 가족 이름 변경, 초대 링크로 들어오면 코드 자동 입력
- 영상을 내 기기에 저장

### 2단계 (서비스 확장)

- 웹 (보관함 열람 중심)
- 의미 검색
- AI 기반 다음 질문 추천
- 가족이 직접 만든 질문 추가

### 3단계 (추가 기능)

- 반려동물 (숏츠, 판별), 일상 기록, 편지
- 웹에서 촬영·업로드
- 여러 가족에 소속, 방장 권한 요청
- 14세 미만 보호자 동의 가입
- 음성 성별 설정

### 만들지 않음

- 생년월일, 전화번호 수집
- 이메일 변경
- 가족 구분 없는 전역 갤러리
